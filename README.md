# DriverTool

Утилита для обновления драйверов Windows — без рекламы, без сторонних установщиков и телеметрии.

Обновления берутся только из Windows Update (подписанные драйверы), собственных сетевых запросов программа не делает.

## Возможности
- Список всех драйверов, подсветка проблемных устройств и драйверов старше 3 лет
- Поиск и установка драйверов через Windows Update (с точкой восстановления)
- Резервная копия и восстановление сторонних драйверов (`pnputil`)
- Быстрый поиск устройства в каталоге Microsoft Update

## Запуск
Нужны Windows 10/11 и Python 3.10+ (только стандартная библиотека):

```
python app.py
```

Для установки и резервного копирования нужны права администратора — программа предложит перезапуск.

## Сборка .exe
```
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name DriverTool --add-data "scripts;scripts" app.py
```

# DriverTool

Утилита для обновления драйверов Windows — без рекламы, без сторонних установщиков и телеметрии.

Драйверы берутся только из двух официальных источников: Windows Update и каталога Microsoft Update.

## Возможности
- **Устройства:** список драйверов, подсветка проблемных и устаревших (порог настраивается), поиск, сортировка, подробности, экспорт в CSV, ссылка на сайт производителя (NVIDIA, AMD, Intel, Realtek, MediaTek)
- **Обновления Windows:** поиск и установка драйверов через Windows Update
- **Каталог Microsoft:** поиск по коду оборудования, скачивание `.cab` с проверкой SHA-256 и цифровой подписи Microsoft, установка через `pnputil`
- **Обслуживание:** удаление старых версий из хранилища драйверов (используемые пакеты пропускаются), список изменений относительно снимка перед установкой, быстрый доступ к точкам восстановления
- **Резервная копия** и восстановление сторонних драйверов
- Перед установкой: снимок версий драйверов и (по желанию) точка восстановления
- Индикатор прогресса, отмена операций, тёмная тема

## Запуск
Нужны Windows 10/11 и Python 3.10+ (только стандартная библиотека):

```
python app.py
```

Для установки, очистки и резервного копирования нужны права администратора — программа предложит перезапуск.

Данные программы (настройки, снимки, загрузки): `%LOCALAPPDATA%\DriverTool`.

## Сборка .exe
```
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name DriverTool --add-data "scripts;scripts" app.py
```

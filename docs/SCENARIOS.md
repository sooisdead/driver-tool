# Сценарии использования

Во всех сценариях, где что-то устанавливается или удаляется, запускайте программу **от администратора**
(жёлтая плашка сверху предложит перезапуск).

## 1. Посмотреть, что устарело
1. Запустите программу — устройства сканируются автоматически (F5 — повторить).
2. Вкладка **Устройства**: красным подсвечены устройства с ошибкой, жёлтым — драйверы старше порога
   (по умолчанию 3 года, меняется в поле «Устаревшим считать старше»).
3. Двойной щелчок по строке (или Ctrl+D) — подробности: версия, коды оборудования, подпись.
4. **Экспорт в CSV** сохраняет текущий список.

## 2. Найти и поставить свежие драйверы автоматически
1. Вкладка **Авто-подбор** → «Найти новее для всех». Программа опрашивает каталог Microsoft по каждому устройству.
2. В списке окажутся только драйверы, у которых версия выше установленной и дата не старше — понизить драйвер нельзя.
3. Выберите нужные → «Установить выбранные». Перед пакетом создаются снимок версий и (по желанию)
   точка восстановления; каждый файл проверяется по SHA-256 и подписи Microsoft.
4. Устройства с найденными обновлениями на вкладке «Устройства» подсвечены зелёным.

## 3. Драйвер для одного устройства
- **Каталог Microsoft:** выберите устройство → «Искать в каталоге Microsoft» → выберите запись → «Скачать и установить».
- **Windows Update:** вкладка «Обновления Windows» → «Искать обновления».
- **Сайт производителя и утилиты:** кнопка «Производитель и утилиты» открывает страницу чипмейкера/производителя ПК
  и предлагает установить фирменную утилиту через winget (Lenovo System Update, Dell Command | Update,
  HP Support Assistant, Intel Driver & Support Assistant, MSI Center).

## 4. Установка не понравилась — откат
Вкладка **Обслуживание → Журнал установок**: выберите запись → «Откатить выбранное». Программа удалит пакеты,
добавленные этой установкой, и Windows вернётся к предыдущему драйверу (он остаётся в хранилище).
Если откат недоступен, используйте «Точки восстановления Windows».

## 5. Навести порядок в хранилище драйверов
«Найти старые версии» показывает пакеты, у которых в хранилище есть более новая версия того же драйвера.
«Удалить выбранные» удаляет их; используемые пакеты Windows не даст удалить.

## 6. Перед переустановкой Windows
Вкладка **Резервная копия** → «Создать копию…». После переустановки — «Восстановить из папки…».

## Горячие клавиши
| Клавиши | Действие |
|---|---|
| F5 | Пересканировать |
| Ctrl+F | Поиск по устройствам |
| Ctrl+D | Подробности |
| Ctrl+E | Экспорт в CSV |
| Ctrl+1…6 | Переключение вкладок |
| Esc | Отменить текущую операцию |

## Где лежат данные
`%LOCALAPPDATA%\DriverTool`: `settings.json`, `journal.json`, `snapshots\`, `driver-tool.log`
(кнопка «Папка с данными»). Ничего не отправляется в сеть, кроме запросов к Microsoft и (по вашей команде) winget.
